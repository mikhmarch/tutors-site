# Telegram-бот для записи к репетиторам

## Что делает бот

- **Открывается с сайта.** Кнопка «Записаться» у Марии ведёт на `t.me/<бот>?start=maria`, и бот сразу показывает Марию.
- **Показывает преподавателей.** Карточки с фото можно листать ◀️ ▶️ и фильтровать по предмету.
- **Собирает заявку в 4 шага:** предмет → кто занимается (класс) → цель → телефон или «пишите в Telegram». Перед отправкой ученик проверяет заявку.
- **Доставляет заявку.** Она приходит Алине в Telegram и сохраняется в таблицу `data/applications.csv` (открывается в Excel).
- **Пересылает переписку.** Если ученик просто пишет боту, сообщение уходит Алине. Алина нажимает «Ответить» на это сообщение, и ответ приходит ученику от имени бота.

## 1. Создать бота (один раз)

1. Откройте в Telegram официальный **@BotFather** и отправьте `/newbot`.
2. Задайте название (например, «Репетиторы Алины Пензевой») и username. Username должен оканчиваться на `bot`, например `penzeva_tutors_bot`.
3. BotFather пришлёт **токен** вида `123456:ABC...`. Никому его не пересылайте.
4. По желанию в BotFather можно добавить аватар (`/setuserpic`) и описание (`/setdescription`). Описание увидят до нажатия «Start».

## 2. Настроить

1. Скопируйте `.env.example` в файл `.env` и впишите токен в `BOT_TOKEN=`.
2. Запустите бота (см. ниже). Алина пишет ему `/id`, бот отвечает числом.
3. Впишите это число в `ADMIN_CHAT_ID=` и перезапустите бота. Теперь заявки приходят Алине.

> Заявки можно получать и в группу, например чтобы видела вся команда. Добавьте бота в группу, отправьте там `/id` и впишите полученное число (оно начинается с минуса).

## 3. Запустить

**На этом компьютере** Python и библиотеки уже установлены (в папке `.venv`). Чтобы запустить бота, откройте `start.bat` двойным щелчком.

**На другом компьютере или сервере** нужен Python 3.10 или новее:

```bash
pip install -r requirements.txt
python bot.py
```

Бот работает, пока запущена программа. Чтобы он отвечал круглосуточно, его размещают на сервере. Подойдёт самый дешёвый VPS с Linux, например у Timeweb Cloud, Selectel или Beget. Пример службы systemd, `/etc/systemd/system/tutorbot.service`:

```ini
[Unit]
Description=Tutor bot
After=network.target

[Service]
WorkingDirectory=/opt/tutorbot
ExecStart=/opt/tutorbot/.venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем выполните `sudo systemctl enable --now tutorbot`.

## 4. Подключить к сайту

В `index.html` замените строку

```js
const TG_URL = 'https://t.me/your_username';
```

на ссылку бота, например `'https://t.me/penzeva_tutors_bot'`. Метки преподавателей сайт добавит сам.

## Как поменять тексты и преподавателей

Всё лежит в `tutors.py`: имена, предметы, короткое описание (`about`), варианты классов, приветствие и текст после заявки. Фото лежат в `photos/`. Новому преподавателю нужны запись в `TUTORS` и фото в этой папке. Если преподаватель должен быть и на сайте, добавьте ему карточку в `index.html` с той же меткой в `data-bot`.
